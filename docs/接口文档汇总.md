## 1. OpenAI 兼容接口

> **Base URL**: `https://your-domain.com`  
> **认证**: `Authorization: Bearer {API_KEY}`

```

  "success": false,

{
  "error": {
    "message": "错误信息",
    "type": "invalid_request_error",
    "code": "invalid_api_key"
  }
}
```

## 13. 常见错误码

| 错误码 | HTTP 状态 | 说明 |
|--------|----------|------|
| `invalid_api_key` | 401 | API Key 无效 |
| `insufficient_user_quota` | 402 | 余额不足 |
| `model_not_found` | 404 | 模型未配置渠道 |
| `task_not_exist` | 404 | 任务不存在 |
| `rate_limit_exceeded` | 429 | 请求过于频繁 |
| `fail_to_fetch_task` | 500 | 上游请求失败 |
| `INVALID_FILE_CONTENT` | 400 | 文件格式不正确 |
| `FILE_DOWNLOAD_FAILED` | 400 | 文件下载失败 |
