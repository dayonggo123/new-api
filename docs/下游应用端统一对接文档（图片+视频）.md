# 下游应用端统一对接文档（图片 + 视频）

> **版本**：v1.0  
> **日期**：2026-07-07  
> **适用范围**：所有通过 new-api 对接图片/视频生成能力的下游应用  
> **设计目标**：用一套 OpenAI 兼容的请求格式，统一接入 GeminiGen、APIMart、Seedream、OpenAI 等渠道的图片和视频模型。

---

## 1. 通用约定

### 1.1 Base URL

```
https://<your-domain>/v1
```

- 生产示例：`https://heharse.cloud/api/v1`
- 所有请求都走 `/v1` 前缀，new-api 内部根据 `model` 参数路由到对应渠道。

### 1.2 认证方式

```http
Authorization: Bearer <your-new-api-token>
```

Token 在后台「令牌」页面生成。new-api 中间件会自动处理 `sk-` 前缀，传 `Bearer sk-xxx` 或 `Bearer xxx` 都可以。

### 1.3 统一路由规则

下游应用**只需要关心 `model` 参数**，new-api 负责把请求分发到对应渠道：

| 模型示例 | 对应渠道 | 备注 |
|---------|---------|------|
| `nano-banana-pro` / `nano-banana-2` / `imagen-4` | GeminiGen | 走 `/uapi/v1/generate_image` 上游 |
| `grok-image` | GeminiGen | 走 `/uapi/v1/imagen/grok` 上游 |
| `meta-ai-image` | GeminiGen | 走 `/uapi/v1/meta_ai/generate` 上游 |
| `gpt-image-2` / `dall-e-3` | OpenAI / APIMart 等 | 走 `/v1/images/generations` 上游 |
| `doubao-seedream-4-5` | VolcEngine / Ark | 标准 Images API |
| `veo-3.1` / `veo-3.1-fast` / `seedance-2` / `kling` | GeminiGen | 走 `/uapi/v1/video-gen/{model}` 上游 |
| `grok-video` / `grok-3` | GeminiGen | 走 `/uapi/v1/video-gen/grok` 上游 |

## 2. 统一文件上传接口

下游应用在使用图片/视频生成前，如果需要上传本地参考图、视频或通用文件，应统一走本接口。上传成功后返回持久 URL，再传给图片/视频生成接口。

### 2.1 标准端点

```http
POST /api/v1/upload
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 是 | 文件类型分类：`image`、`video`、`audio`、`file`、`material` |
| `permanent` | bool | 否 | 是否永久保留，默认 `false`。图片/视频参考图建议传 `true` |
| `prefix` | string | 否 | 额外路径前缀，仅允许 `[a-zA-Z0-9_-]` |
| `retain_name` | bool | 否 | 是否保留原文件名，默认 `false` |

请求体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `file` | File | 单文件上传 |
| `files` | File[] | 多文件上传，优先于 `file` |

### 2.2 响应格式

```json
{
  "success": true,
  "data": [
    {
      "url": "https://heharse.cloud/api/uploads/permanent/image/20260707/abc123.png",
      "filename": "abc123.png",
      "original_name": "ref.jpg",
      "size": 204800,
      "mime_type": "image/png",
      "type": "image",
      "permanent": true
    }
  ]
}
```

### 2.3 上传示例

```bash
curl -X POST "https://heharse.cloud/api/v1/upload?type=image&permanent=true" \
  -H "Authorization: Bearer <token>" \
  -F "file=@ref.jpg"
```

多文件上传：

```bash
curl -X POST "https://heharse.cloud/api/v1/upload?type=material" \
  -H "Authorization: Bearer <token>" \
  -F "files=@1.jpg" \
  -F "files=@2.jpg"
```

### 2.4 文件大小限制

| type | 默认大小限制 | 允许 MIME |
|------|-------------|----------|
| `image` | 50 MB | image/* |
| `video` | 500 MB | video/* |
| `audio` | 100 MB | audio/* |
| `file` | 100 MB | */* |
| `material` | 100 MB | image/*, video/* |

超过限制会返回 HTTP 413。

### 2.5 与旧上传接口的关系

统一接口 `POST /api/v1/upload` 是推荐的新入口。旧接口仍保持兼容：

| 旧接口 | 映射 |
|--------|------|
| `POST /uapi/v1/upload_images` | `type=image` |
| `POST /uapi/v1/upload_videos` | `type=video` |
| `POST /uapi/v1/r2/upload-image` | `type=image`（优先 R2） |
| `POST /api/admin/tk/materials` | `type=material` |


## 3. 图片生成统一接口

### 3.1 标准端点

```http
POST /v1/images/generations
Authorization: Bearer <token>
Content-Type: application/json
```

> 对于部分耗时较长的模型（如 `gpt-image-2`），可在 URL 加 `?async=true` 强制走异步任务，避免网关超时：
> ```http
> POST /v1/images/generations?async=true
> ```

### 3.2 通用请求字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | ✅ | 图片模型名，如 `dall-e-3`、`gpt-image-2`、`doubao-seedream-4-5`、`nano-banana-2` |
| `prompt` | string | ✅ | 图片描述 |
| `n` | int | ❌ | 生成数量，默认 1 |
| `size` | string | ❌ | 尺寸。OpenAI 格式：`1024x1024`；Seedream 格式：`2K`/`3K`/`4K`；GeminiGen 格式：`1K`/`2K`/`4K`（也可传 `1024x1024`） |
| `aspect_ratio` | string | ❌ | 比例：`1:1`、`16:9`、`9:16`、`4:3`、`3:4` 等。若同时传 `size`，渠道各自有映射策略 |
| `quality` | string | ❌ | 质量，如 `standard`、`hd` |
| `style` | string | ❌ | 艺术风格，如 `Photorealistic`、`Anime General`、`3D Render` |
| `response_format` | string | ❌ | `url`（默认）或 `b64_json` |
| `output_format` | string | ❌ | 输出格式：`png`、`jpeg`、`webp` |
| `background` | string | ❌ | gpt-image-2 支持：`transparent` / `opaque` |
| `image` | string / array | ❌ | 参考图 URL（数组），用于 Seedream 等图生图 |
| `image_urls` | array | ❌ | 参考图 URL 数组（APIMart 等渠道偏好字段） |
| `ref_images` | file / string | ❌ | multipart 文件字段或 HTTP URL，用于 GeminiGen 等图生图 |
| `user` | string | ❌ | 用户标识 |

### 3.3 同步响应示例

```json
{
  "created": 1760759307,
  "data": [
    {
      "url": "https://heharse.cloud/api/image-proxy/xxx.png",
      "revised_prompt": "A cute cat sitting on a sofa..."
    }
  ]
}
```

### 3.4 异步响应示例

当使用 `?async=true` 或上游本身是异步渠道（如 APIMart、GeminiGen 通过标准 Images API 接入时）会返回任务：

```json
{
  "id": "task_xxx",
  "task_id": "task_xxx",
  "object": "image.generation",
  "model": "gpt-image-2",
  "status": "queued",
  "progress": "0%",
  "created_at": 1760759307
}
```

### 3.5 异步轮询

```http
GET /v1/images/tasks/{task_id}
Authorization: Bearer <token>
```

**成功响应**：

```json
{
  "id": "task_xxx",
  "task_id": "task_xxx",
  "object": "image.generation",
  "status": "completed",
  "progress": "100%",
  "created_at": 1760759307,
  "completed_at": 1760759400,
  "metadata": {
    "url": "https://heharse.cloud/api/image-proxy/xxx.png"
  }
}
```

## 4. 视频生成统一接口

### 4.1 标准端点

```http
POST /v1/videos/generations
Authorization: Bearer <token>
Content-Type: application/json
```

视频生成均为异步任务，提交后立即返回 `task_id`。

### 4.2 通用请求字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | ✅ | 视频模型名，如 `veo-3.1`、`veo-3.1-fast`、`seedance-2`、`kling`、`grok-video` |
| `prompt` | string | ✅ | 视频描述 |
| `aspect_ratio` | string | ❌ | 宽高比：`16:9`（默认）、`9:16`、`1:1`、`4:3`、`3:4` |
| `resolution` | string | ❌ | 分辨率：`480p` / `720p` / `1080p`（默认 `720p`） |
| `duration` | int | ❌ | 时长（秒）。Veo 默认 8s；Grok 支持 6/10/15；Kling 支持 5/10/15/30 |
| `ref_images` | array / file | ❌ | 参考图 URL 数组或 multipart 文件 |
| `video_urls` | array | ❌ | 视频参考 URL 数组（视频编辑场景） |
| `generation_type` | string | ❌ | 生成类型，如 `reference`（参考图融合） |

### 4.3 提交响应示例

```json
{
  "id": "task_xxx",
  "task_id": "task_xxx",
  "object": "video.generation",
  "model": "veo-3.1",
  "status": "queued",
  "progress": "0%",
  "created_at": 1760759307
}
```

### 4.4 异步轮询

```http
GET /v1/videos/{task_id}
Authorization: Bearer <token>
```

**成功响应**：

```json
{
  "task_id": "task_xxx",
  "status": "completed",
  "video_url": "https://heharse.cloud/api/video-proxy/xxx.mp4",
  "progress": "100%"
}
```

## 5. 参考图统一处理

不同渠道对参考图字段名偏好不同，new-api 已做兼容转换。下游应用按以下优先级选择即可：

| 场景 | 推荐字段 | 支持格式 |
|------|---------|----------|
| 标准 OpenAI 图片编辑 / 图生图 | `image`（JSON 字符串/数组）或 `image_urls`（JSON 数组） | HTTP URL、base64 data URL、file_id |
| GeminiGen 图片生成 | `ref_images`（multipart 文件 / HTTP URL / base64） | 文件、URL、base64 |
| APIMart 图片编辑 | `image`（multipart 文件）或 `image_urls`（JSON 数组） | 文件、URL |
| 视频生成参考图 | `ref_images` | 文件、URL |

**推荐做法**：

1. 如果是本地图片，先调用 `POST /api/v1/upload?type=image&permanent=true` 上传获取持久 URL；
2. 然后在图片/视频请求里用 URL 形式传 `image` / `image_urls` / `ref_images`，避免 multipart 跨渠道兼容问题。

**示例**：先上传

```bash
curl -X POST "https://heharse.cloud/api/v1/upload?type=image&permanent=true" \
  -H "Authorization: Bearer <token>" \
  -F "file=@cat.jpg"
```

返回：

```json
{
  "success": true,
  "data": [
    {
      "url": "https://heharse.cloud/api/uploads/permanent/image/20260707/abc123.png"
    }
  ]
}
```

再调用图片生成：

```json
{
  "model": "nano-banana-2",
  "prompt": "把这只猫变成宇航员",
  "image_urls": ["https://heharse.cloud/api/uploads/permanent/image/20260707/abc123.png"],
  "size": "1K"
}
```

## 6. 何时使用 UAPI 接口

大部分场景下，标准 `/v1/images/generations` 和 `/v1/videos/generations` 已足够。以下情况可改用 UAPI：

| 场景 | 推荐接口 | 原因 |
|------|---------|------|
| 需要 GeminiGen 特有的 `style`、`resolution` 档位（1K/2K/4K） | `/uapi/v1/generate_image` | 字段更贴近上游 |
| 需要 GeminiGen 视频模型的精确路径（如 `/uapi/v1/video-gen/seedance`） | `/uapi/v1/video-gen/{model}` | 上游直接透传 |
| 下游客户端已经按 GeminiGen 格式封装 | `/uapi/v1/generate_image` / `/uapi/v1/video-gen/{model}` | 减少改造 |

## 7. 统一异步轮询流程

无论是图片还是视频，异步流程都一样：

```
1. POST /v1/images/generations 或 /v1/videos/generations
2. 获取 task_id
3. 循环 GET /v1/images/tasks/{task_id} 或 /v1/videos/{task_id}
4. status == completed 时取 url/video_url
5. status == failure 时取 fail_reason
```

**建议轮询间隔**：3-5 秒。图片通常 10-60 秒，视频通常 30-120 秒。

## 8. 错误码

| HTTP 状态码 | 错误码 | 说明 |
|------------|--------|------|
| 401 | - | 认证失败，检查 Token |
| 429 | - | 限流 |
| 413 | - | 请求体/文件过大 |
| 500 | - | 服务器内部错误 |
| - | `model_not_found` | 模型未配置渠道 |
| - | `insufficient_user_quota` | 余额不足 |
| - | `task_not_exist` | 任务不存在或已过期 |
| - | `fail_to_fetch_task` | 上游请求失败（参考图无效等） |
| - | `INVALID_FILE_CONTENT` | 参考图文件格式不正确 |

## 9. 统一 SDK 示例（Python）

```python
import requests
import time

BASE_URL = "https://heharse.cloud/api/v1"
API_KEY = "sk-xxx"

headers = {"Authorization": f"Bearer {API_KEY}"}

# ---------- 图片生成 ----------
def generate_image(model: str, prompt: str, size: str = "1024x1024", image_urls=None, async_mode=False):
    url = f"{BASE_URL}/images/generations"
    if async_mode:
        url += "?async=true"
    payload = {
        "model": model,
        "prompt": prompt,
        "size": size,
        "n": 1,
        "response_format": "url"
    }
    if image_urls:
        payload["image_urls"] = image_urls
    resp = requests.post(url, headers=headers, json=payload)
    return resp.json()

# ---------- 视频生成 ----------
def generate_video(model: str, prompt: str, aspect_ratio="16:9", resolution="720p", duration=8):
    payload = {
        "model": model,
        "prompt": prompt,
        "aspect_ratio": aspect_ratio,
        "resolution": resolution,
        "duration": duration
    }
    resp = requests.post(f"{BASE_URL}/videos/generations", headers=headers, json=payload)
    return resp.json()

# ---------- 轮询 ----------
def poll_task(task_id: str, endpoint: str = "images/tasks", interval=5, timeout=300):
    start = time.time()
    while time.time() - start < timeout:
        resp = requests.get(f"{BASE_URL}/{endpoint}/{task_id}", headers=headers)
        data = resp.json()
        status = data.get("status") or data.get("data", {}).get("status")
        if status in ("completed", "SUCCESS"):
            return data
        if status in ("failure", "FAILURE"):
            raise Exception(f"Task failed: {data}")
        print(f"Progress: {data.get('progress', '0%')}")
        time.sleep(interval)
    raise TimeoutError("Poll timeout")

# 使用示例
result = generate_image("nano-banana-2", "a cute cat", size="1K", async_mode=True)
task_id = result["task_id"]
image_result = poll_task(task_id, "images/tasks")
print(image_result)

result = generate_video("veo-3.1", "a cat running on grass")
video_result = poll_task(result["task_id"], "videos")
print(video_result)
```

## 10. 统一 SDK 示例（JavaScript / TypeScript）

```typescript
class MediaClient {
  constructor(private baseURL: string, private apiKey: string) {}

  private headers() {
    return { Authorization: `Bearer ${this.apiKey}`, "Content-Type": "application/json" };
  }

  async generateImage(model: string, prompt: string, size = "1024x1024", asyncMode = false) {
    const url = `${this.baseURL}/images/generations${asyncMode ? "?async=true" : ""}`;
    const resp = await fetch(url, {
      method: "POST",
      headers: this.headers(),
      body: JSON.stringify({ model, prompt, size, n: 1, response_format: "url" }),
    });
    return resp.json();
  }

  async generateVideo(model: string, prompt: string, options: any = {}) {
    const resp = await fetch(`${this.baseURL}/videos/generations`, {
      method: "POST",
      headers: this.headers(),
      body: JSON.stringify({ model, prompt, ...options }),
    });
    return resp.json();
  }

  async pollTask(taskId: string, endpoint: "images/tasks" | "videos", interval = 5000) {
    while (true) {
      const resp = await fetch(`${this.baseURL}/${endpoint}/${taskId}`, { headers: this.headers() });
      const data = await resp.json();
      const status = data.status || data.data?.status;
      if (status === "completed" || status === "SUCCESS") return data;
      if (status === "failure" || status === "FAILURE") throw new Error(JSON.stringify(data));
      console.log("Progress:", data.progress || data.data?.progress);
      await new Promise((r) => setTimeout(r, interval));
    }
  }
}

const client = new MediaClient("https://heharse.cloud/api/v1", "sk-xxx");

const imgTask = await client.generateImage("gpt-image-2", "a futuristic city", "1024x1024", true);
const imgResult = await client.pollTask(imgTask.task_id, "images/tasks");
console.log(imgResult);

const videoTask = await client.generateVideo("veo-3.1", "a cat running");
const videoResult = await client.pollTask(videoTask.task_id, "videos");
console.log(videoResult);
```

## 11. 注意事项

1. **异步模式**：`gpt-image-2`、GeminiGen、APIMart 等模型生成耗时较长，建议优先使用 `?async=true`。
2. **URL 持久化**：new-api 返回的 `url` 通常是本站代理地址，不会因上游临时链接过期而失效。
3. **参考图**：优先使用 URL 形式，避免 multipart 在不同渠道间的字段名差异。
4. **Windows 客户端**：使用 Python `requests` 或 Rust `reqwest` 时可能受系统代理影响，建议 `session.trust_env = False` 或 `Client::builder().no_proxy().build()`。
