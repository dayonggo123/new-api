## 2. 获取提示词列表

### 接口

```
GET /public/prompts?category_id={分类ID}&keyword={关键词}&page={页码}&page_size={每页条数}
```

### 请求参数

| 参数名      | 类型   | 必填 | 说明               |
|-------------|--------|------|--------------------|
| category_id | int    | 否   | 分类ID筛选         |
| keyword     | string | 否   | 关键词搜索         |
| page        | int    | 否   | 页码，默认 1       |
| page_size   | int    | 否   | 每页条数，默认 20  |

## 4. 获取媒体文件（封面图 / 视频）

### 接口

```
GET /public/prompt-media/{media_id}
```

### 说明

- `cover_image_url` 和 `video_url` 中的路径均为 `/api/public/prompt-media/{id}` 格式
- 直接通过该接口访问即可获取对应的图片或视频二进制流
- 支持在 `<img>` 和 `<video>` 标签中直接引用该 URL

### 前端展示示例

#### 图片提示词

```html
<img src="https://your-domain.com/api/public/prompt-media/abc123" alt="提示词封面" />
```

#### 视频提示词

```html
<!-- 视频播放器，使用 cover_image_url 作为 poster（首帧/封面） -->
<video
  src="https://your-domain.com/api/public/prompt-media/ghi789"
  poster="https://your-domain.com/api/public/prompt-media/def456"
  controls
  style="width: 100%; max-width: 640px;"
></video>
```

## 5. 字段说明

### 核心字段

| 字段名          | 类型    | 说明                                                         |
|-----------------|---------|--------------------------------------------------------------|
| id              | int     | 提示词唯一ID                                                 |
| title           | string  | 标题                                                         |
| content         | string  | 提示词内容（中文）                                           |
| content_en      | string  | 提示词内容（英文）                                           |
| cover_image_url | string  | 封面图 URL，`/api/public/prompt-media/{id}`                  |
| video_url       | string  | 视频 URL，`/api/public/prompt-media/{id}`，图片类型为空字符串 |
| media_type      | string  | 内容类型：`image`（图片）或 `video`（视频）                   |
| category_name   | string  | 分类名称                                                     |
| tags            | string  | JSON 数组字符串，如 `["科幻","飞船"]`                         |
| variables       | string  | JSON 数组字符串，变量定义，为空表示无变量                     |
| usage_count     | int     | 使用次数                                                     |

### 如何判断是图片还是视频提示词

```javascript
if (prompt.media_type === 'video') {
  // 视频类型：展示视频播放器，用 cover_image_url 做 poster
  // video_url 为视频播放地址
} else {
  // 图片类型：展示封面图
  // cover_image_url 为图片地址
}
```

## 6. 下游接入建议

### 列表页展示

```javascript
// 遍历 items，根据 media_type 渲染不同卡片
items.forEach(prompt => {
  if (prompt.media_type === 'video') {
    // 卡片显示视频缩略图（cover_image_url）+ 播放图标覆盖层
    // 点击进入详情页播放视频
  } else {
    // 卡片显示图片（cover_image_url）
  }
});
```

### 详情页展示

```javascript
if (prompt.media_type === 'video') {
  // 展示视频播放器
  <video src={prompt.video_url} poster={prompt.cover_image_url} controls />
} else {
  // 展示大图
  <img src={prompt.cover_image_url} />
}

// 下方展示提示词内容，供用户复制使用
<p>{prompt.content}</p>
```

### 复制提示词内容

用户点击"复制"时，根据用户语言偏好返回对应内容：

```javascript
const text = userLang === 'en' && prompt.content_en
  ? prompt.content_en
  : prompt.content;
// 复制 text 到剪贴板
```

## 7. 完整调用流程示例

```javascript
// 1. 获取分类列表
const categoriesRes = await fetch('/api/public/prompt-categories');
const categories = await categoriesRes.json();

// 2. 获取某个分类下的提示词列表（如 AI视频 分类）
const promptsRes = await fetch('/api/public/prompts?category_id=2&page=1&page_size=20');
const promptsData = await promptsRes.json();

// 3. 用户点击某个视频提示词，获取详情
const detailRes = await fetch('/api/public/prompts/2');
const detail = await detailRes.json();

// 4. 展示视频
const prompt = detail.data;
if (prompt.media_type === 'video') {
  videoElement.src = prompt.video_url;           // 视频地址
  videoElement.poster = prompt.cover_image_url;  // 封面/首帧
}
```
