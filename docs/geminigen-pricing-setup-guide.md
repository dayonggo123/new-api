# GeminiGen 视频生成充值方案 - 配置指南

## 概述

本方案基于 new-api 现有的 **subscription_plans（订阅套餐）** + **group_ratio（分组倍率）** 系统，无需任何代码修改即可上线。

---

## 第一步：创建用户分组（分组与模型倍率设置）

**路径：** 管理员后台 → 系统设置 → 分组与模型倍率设置

点击「添加分组」，依次创建以下分组：

| 分组名称 | 倍率 | 说明 |
|---------|------|------|
| `video_creator` | 1 | 视频创作者套餐用户分组 |
| `video_pro` | 0.8 | 视频专业版用户分组 |
| `enterprise` | 0.6 | 企业API用户分组 |

> `default` 分组已存在，保持倍率 1 即可（未订阅用户的对话模型按原价）。

---

## 第二步：设置模型定价（按分组）

**路径：** 管理员后台 → 系统设置 → 分组与模型定价设置

### 2.1 为视频模型设置成本价

在「模型定价编辑器」中添加以下模型并设置价格：

| 模型 | 模型类型 | 计费方式 | 固定价格 |
|------|---------|---------|---------|
| `veo_3_1-light` | 视频 | 按次计费 | $0.05 |
| `veo_3_1-fast` | 视频 | 按次计费 | $0.40 |
| `veo_3_1` | 视频 | 按次计费 | $0.75 |
| `veo_3_1-4K` | 视频 | 按次计费 | $1.50 |
| `sora-2` | 视频 | 按次计费 | $0.50 |
| `gpt-image-2` | 图片 | 按次计费 | $0.02 |

### 2.2 分组定价生效原理

- **default 组用户**：实际价格 = 模型定价 × 2.0（视频倍率）
  - Veo Fast: $0.40 × 2 = $0.80/条
- **video_creator 组用户**：实际价格 = 模型定价 × 1.0
  - Veo Fast: $0.40 × 1 = $0.40/条
- **video_pro 组用户**：实际价格 = 模型定价 × 0.8
  - Veo Fast: $0.40 × 0.8 = $0.32/条
- **enterprise 组用户**：实际价格 = 模型定价 × 0.6
  - Veo Fast: $0.40 × 0.6 = $0.24/条

## 第四步：配置支付金额选项

**路径：** 管理员后台 → 系统设置 → 支付设置

### 4.1 充值金额选项

设置预设充值金额（方便用户快速选择）：

```json
[10, 29, 69, 100, 199, 500]
```

### 4.2 金额折扣（可选）

设置充值折扣激励大额充值：

```json
{
  "100": 0.95,
  "200": 0.9,
  "500": 0.85
}
```

含义：
- 充值 100 元 → 实际到账 105 quota（95 折）
- 充值 200 元 → 实际到账 222 quota（9 折）
- 充值 500 元 → 实际到账 588 quota（85 折）

## 第五步：配置用户默认计费偏好

**路径：** 用户个人设置页面（或管理员修改用户设置）

建议新用户默认使用 `subscription_first`（优先使用订阅额度）：
- 有订阅套餐时先用套餐额度
- 套餐额度用完后再扣钱包额度
- 无订阅时直接扣钱包额度

## 用户使用流程

1. **新用户注册** → 默认在 `default` 分组
2. **免费领取** → 后台领取「免费体验」套餐 → 每日 500 额度
3. **生成视频** → 用额度生成视频（Veo Light ~250 quota/条）
4. **额度用完** → 提示升级套餐
5. **购买套餐** → 选择「视频创作者/专业版/企业API」→ 支付后自动升级分组
6. **享受低价** → 视频模型按对应分组倍率计费

---

## 注意事项

1. **分组倍率仅影响视频/图片模型**：对话模型（chat）保持 1x 倍率不变
2. **套餐到期自动降级**：订阅到期后自动回到 `default` 分组，视频价格恢复 2x
3. **免费套餐每人限1次**：防止薅羊毛
4. **支持续费**：相同套餐可重复购买，额度累加
5. **可随时取消**：取消订阅后当前周期内仍可使用剩余额度
