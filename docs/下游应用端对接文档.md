# new-api 下游应用端对接文档

> **版本**：v1.0  
> **日期**：2026-07-03  
> **适用范围**：对接火山方舟（VolcEngine/Ark）、Google Gemini、OpenAI 官方渠道能力

---

## 1. 通用约定

### 1.1 Base URL

```
https://<your-domain>/v1
```

- 例如：`https://api.heharse.com/v1`
- 所有接口均统一通过 `/v1` 前缀暴露，new-api 内部按渠道分发到对应上游。

### 1.2 认证方式

与 OpenAI 官方一致，使用 Bearer Token：

```bash
Authorization: Bearer <your-new-api-token>
```

new-api token 在后台「令牌」页面生成，按渠道分发逻辑由服务端配置决定。

### 1.3 渠道分发规则

new-api 按请求中的 `model` 参数将请求路由到对应渠道，配置在后台完成。下游客户端无需关心上游渠道类型。

## 2. 通用接口清单

| 接口 | 方法 | 说明 |
|------|------|------|
| `/v1/models` | GET | 列出可用模型 |
| `/v1/chat/completions` | POST | 文本/多模态对话（火山、Gemini、OpenAI 均支持） |
| `/v1/responses` | POST | OpenAI Responses API（多模态输入） |
| `/v1/responses/compact` | POST | OpenAI Responses 会话压缩 |
| `/v1/completions` | POST | 文本补全 |
| `/v1/embeddings` | POST | Embedding |
| `/v1/audio/transcriptions` | POST | 语音转文字（Whisper-1） |
| `/v1/audio/translations` | POST | 语音翻译 |
| `/v1/audio/speech` | POST | 语音合成 |
| `/v1/images/generations` | POST | 图片生成（OpenAI Images API / DALL·E / gpt-image-2 / Seedream / Gemini） |
| `/v1/images/edits` | POST | 图片编辑 |
| `/v1/videos/generations` | POST | 视频生成（Veo / Omni Flash / Kling 等异步任务） |
| `/v1/videos/{task_id}` | GET | 查询视频生成任务结果 |
| `/v1/files` | POST | 上传文件 |
| `/v1/files` | GET | 列出文件 |
| `/v1/files/{file_id}` | GET | 查询文件详情 |
| `/v1/files/{file_id}` | DELETE | 删除文件 |
| `/v1/images/tasks/{task_id}` | GET | 查询图片异步任务结果 |
| `/v1/rerank` | POST | Rerank 接口 |

## 3. Chat Completions 多模态对话

### 3.1 请求格式

```http
POST /v1/chat/completions
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "model": "doubao-seed-1-6-thinking-250715",
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "描述这张图片" },
        { "type": "image_url", "image_url": { "url": "https://example.com/a.png" } },
        { "type": "input_audio", "input_audio": { "data": "base64...", "format": "mp3" } }
      ]
    }
  ]
}
```

### 3.2 支持的 content part 类型

| content part 类型 | 字段 | 支持来源 | 说明 |
|------------------|------|---------|------|
| `text` | `text` | 文本 | 直接透传 |
| `image_url` | `image_url.url` | URL / base64 / file_id | 火山：`file-xxx` 或 `data:image/*;base64,...` |
| `video_url` | `video_url` | URL / file_id | 火山/Gemini 视频理解模型 |
| `input_audio` | `input_audio` | base64 / URL / file_id | 格式：`{"data":"base64","format":"mp3"}` 或 `{"url":"..."}` 或 `{"file_id":"..."}` |
| `file` | `file` | file_id / URL / file_data | 用于 PDF 文档理解：`{"file_id":"..."}` 或 `{"filename":"x.pdf","file_data":"base64"}` 或 `{"url":"..."}` |

### 3.3 curl 示例

```bash
curl https://api.heharse.com/v1/chat/completions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seed-1-6-thinking-250715",
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "总结这份 PDF 的内容" },
          { "type": "file", "file": { "file_id": "file-20251018114827-6zgrb" } }
        ]
      }
    ]
  }'
```

## 4. Responses API（OpenAI 渠道）

### 4.1 请求格式

```http
POST /v1/responses
Authorization: Bearer <token>
Content-Type: application/json
```

### 4.2 支持的 input 类型

| input 类型 | 字段 | 示例 | 说明 |
|-----------|------|------|------|
| `input_text` | `text` | `{"type": "input_text", "text": "..."}` | 普通文本 |
| `input_image` | `image_url` / `file_id` | `{"type": "input_image", "image_url": "https://...", "detail": "high"}` | 支持 URL、base64、file_id，detail 可选 |
| `input_file` | `file_url` / `file_id` / `filename` + `file_data` | `{"type": "input_file", "file_url": "https://..."}` | 文件 URL 或已上传 file_id |

### 4.3 请求示例

```json
{
  "model": "gpt-4.1",
  "input": [
    { "type": "input_text", "text": "图中有什么？" },
    { "type": "input_image", "image_url": "https://example.com/a.png", "detail": "high" },
    { "type": "input_file", "file_url": "https://example.com/report.pdf" }
  ]
}
```

### 4.4 curl 示例

```bash
curl https://api.heharse.com/v1/responses \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1",
    "input": [
      { "type": "input_text", "text": "分析这张图片" },
      { "type": "input_image", "image_url": "https://example.com/a.png", "detail": "high" }
    ]
  }'
```

## 5. Images API（图片生成）

### 5.1 请求格式

```http
POST /v1/images/generations
Authorization: Bearer <token>
Content-Type: application/json
```

### 5.2 通用请求字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 如 `dall-e-3`、`gpt-image-2`、`doubao-seedream-4-5` |
| `prompt` | string | 是 | 提示词 |
| `n` | integer | 否 | 生成数量 |
| `size` | string | 否 | 尺寸，如 `1024x1024`、`2K`、`3K`、`4K`（Seedream） |
| `quality` | string | 否 | 质量 |
| `response_format` | string | 否 | `url` 或 `b64_json` |
| `style` | string/object | 否 | 风格 |
| `image` | string/array | 否 | 参考图（Seedream 多图参考） |
| `sequential_image_generation` | string | 否 | Seedream 组图生成：`disabled` / `auto` |
| `output_format` | string | 否 | 输出格式：`png` / `jpeg` / `webp` |
| `background` | string | 否 | gpt-image-2 支持：`transparent` / `opaque` |
| `user` | string | 否 | 用户标识 |

### 5.3 curl 示例（OpenAI DALL·E）

```bash
curl https://api.heharse.com/v1/images/generations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dall-e-3",
    "prompt": "a cat",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
```

### 5.4 curl 示例（Seedream 多图参考）

```bash
curl https://api.heharse.com/v1/images/generations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "将图1的服装换为图2的服装",
    "image": [
      "https://example.com/outfit1.png",
      "https://example.com/outfit2.png"
    ],
    "sequential_image_generation": "disabled",
    "size": "2K",
    "output_format": "png",
    "watermark": false
  }'
```

### 5.5 响应示例

```json
{
  "created": 1760759307,
  "data": [
    { "url": "https://..." },
    { "b64_json": "..." }
  ]
}
```

## 6. Files API（文件上传/列表/删除）

### 6.1 上传文件

```http
POST /v1/files
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | file | 与 `url` 二选一 | 本地二进制文件 |
| `url` | string | 与 `file` 二选一 | 文件公网 URL（OpenAI 渠道已支持） |
| `purpose` | string | 否 | 文件用途，默认 `user_data` |
| `preprocess_configs` | object | 否 | 火山视频上传时可用，如 `{"video":{"fps":0.3}}` |

#### curl 示例（本地文件）

```bash
curl https://api.heharse.com/v1/files \
  -H "Authorization: Bearer $TOKEN" \
  -F 'purpose=user_data' \
  -F 'file=@/path/to/video.mp4'
```

#### curl 示例（URL 上传）

```bash
curl https://api.heharse.com/v1/files \
  -H "Authorization: Bearer $TOKEN" \
  -F 'purpose=user_data' \
  -F 'url=https://example.com/video.mp4'
```

### 6.2 列出文件

```http
GET /v1/files
Authorization: Bearer <token>
```

```bash
curl https://api.heharse.com/v1/files \
  -H "Authorization: Bearer $TOKEN"
```

### 6.3 查询文件详情

```http
GET /v1/files/{file_id}
Authorization: Bearer <token>
```

```bash
curl https://api.heharse.com/v1/files/file-20251018114827-6zgrb \
  -H "Authorization: Bearer $TOKEN"
```

### 6.4 删除文件

```http
DELETE /v1/files/{file_id}
Authorization: Bearer <token>
```

```bash
curl -X DELETE https://api.heharse.com/v1/files/file-20251018114827-6zgrb \
  -H "Authorization: Bearer $TOKEN"
```

### 6.5 响应结构

```json
{
  "object": "file",
  "id": "file-20251018114827-6zgrb",
  "purpose": "user_data",
  "filename": "demo.mp4",
  "bytes": 695110,
  "mime_type": "video/mp4",
  "created_at": 1760759307,
  "expire_at": 1761364107,
  "status": "processed"
}
```

> 注意：Google Gemini 渠道上传时还会额外返回 `file_uri` 字段，用于后续多模态 Chat 引用。

## 8. 渠道特定说明

### 8.1 火山方舟（VolcEngine / Ark）

- **聊天模型**：`doubao-seed-1-6-thinking-250715` 等
- **图片模型**：`doubao-seedream-4-5`、`doubao-seedream-5-0` 等
- **图片生成特性**：支持 `size: 2K/3K/4K`、`image` 多图参考、`sequential_image_generation` 组图生成
- **文件上传**：`preprocess_configs` 可用于视频 fps 等参数
- **多模态输入**：`image_url` / `video_url` / `input_audio` / `file` 均支持 URL、base64、file_id

### 8.2 Google Gemini

- **聊天模型**：`gemini-2.5-pro` 等
- **图片生成模型**：`gemini-3.1-flash-image`、`gemini-3-pro-image` 等
- **视频生成模型**：`veo-3.1-generate-preview`、`gemini-omni-flash-preview`
- **文件上传**：单文件最大 2GB，文件 URI 48 小时有效，会返回 `file_uri` 字段
- **多模态输入**：`image_url` / `video_url` / `input_audio` / `file` 支持 URL、base64、file_uri

### 8.3 OpenAI 官方

- **聊天模型**：`gpt-4o`、`gpt-4.1` 等
- **图片生成模型**：`dall-e-3`、`gpt-image-2` 等
- **Responses API**：`gpt-4o`、`gpt-4.1` 等
- **Files API**：`purpose` 可选，支持本地文件和 URL 上传
- **图片参数**：`style`、`background`、`output_format`、`output_compression`、`image`、`user` 等字段透传

## 9. Python SDK 示例

使用 OpenAI 官方 SDK 直接对接：

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.heharse.com/v1",
    api_key="<your-new-api-token>",
)

# 图片生成
resp = client.images.generate(
    model="doubao-seedream-4-5",
    prompt="a cat",
    size="2K",
    response_format="url"
)
print(resp.data[0].url)

# 多模态对话
resp = client.chat.completions.create(
    model="doubao-seed-1-6-thinking-250715",
    messages=[
        {
            "role": "user",
            "content": [
                { "type": "text", "text": "描述这张图片" },
                { "type": "image_url", "image_url": { "url": "https://example.com/a.png" } }
            ]
        }
    ]
)
print(resp.choices[0].message.content)

# 文件上传
file_obj = client.files.create(
    file=open("/path/to/video.mp4", "rb"),
    purpose="user_data"
)
print(file_obj.id)
```

## 10. 错误处理

所有接口返回 OpenAI 标准错误格式：

```json
{
  "error": {
    "message": "...",
    "type": "invalid_request_error",
    "code": "..."
  }
}
```

常见错误码：

| HTTP 状态码 | 错误类型 | 说明 |
|------------|---------|------|
| 400 | `invalid_request_error` | 请求参数错误 |
| 401 | `authentication_error` | Token 无效或过期 |
| 429 | `rate_limit_exceeded` | 请求频率超限 |
| 500 | `internal_error` | 服务端内部错误 |
| 503 | `service_unavailable` | 上游服务不可用 |

## 11. 注意事项

1. **渠道配置**：上游渠道类型和模型映射在 new-api 后台配置，客户端按 `model` 参数即可调用。
2. **异步任务**：视频生成是异步任务，需通过 `/v1/videos/{task_id}` 轮询结果。
3. **文件有效期**：Google Gemini 上传的文件 URI 48 小时有效；火山方舟文件有效期取决于上游配置。
4. **多模态文件**：大文件建议先调用 `/v1/files` 上传，再在 Chat 中通过 `file_id` 引用，避免 base64 传输过大。
5. **base64 大小**：建议图片 base64 不超过 10MB，音频/视频 base64 不建议直接使用，优先上传文件。
