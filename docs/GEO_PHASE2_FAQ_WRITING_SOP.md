# GEO 第二阶段：内容改造与 FAQ 写作 SOP

> **面向对象**：运营 / 编辑 / 内容同学
> **目标**：在保留 SEO 的基础上，让文章页和 Prompt 页的内容更易被 AI 引用（GEO 优化）
> **原则**：SEO 继续做，GEO 是新增的一层优化。一篇文章/Prompt 同时服务搜索排名和 AI 引用。

---

## 一、改造范围：先攻头部，再铺长尾

不要一上来就改全部。按**流量和使用数据**选种子内容，验证效果后再扩大。

### 1.1 文章页（选 20 篇）

**筛选标准**（满足任意一条即可入选）：

| 标准 | 说明 |
|------|------|
| 近 3 个月自然搜索流量 Top 20 | 在 Google Search Console 或统计后台查看 |
| 教程类 / 对比类 / 问题解答类 | 天然适合 FAQ 化 |
| 字数 >= 800 字 | 有空间插入 FAQ 区块 |

**优先级排序**：
1. 流量最高且内容为教程/指南的 → 优先改
2. 流量中等但内容质量好的 → 次优先
3. 流量高但内容偏资讯的 → 可延后

### 1.2 Prompt 页（选 30 个）

**筛选标准**（满足任意一条即可入选）：

| 标准 | 说明 |
|------|------|
| 近 30 天使用次数 Top 30 | 在后台 Prompt 管理页查看使用量 |
| 描述字数 > 100 字 | 有解释空间，适合补充使用指南 |
| 含 2 个以上参数/变量 | 用户会有"怎么调参数"的问题 |
| 标题含"教程""指南""步骤""方法" | 用户搜索意图偏向学习 |

**注意**：纯风格词（如"油画风格""赛博朋克"）不改 FAQ，ROI 太低。

## 二、文章页改造规范（5 个语义块）

每篇文章改造后，正文必须包含以下 **5 个语义块**。不需要改标题，重点是正文结构调整。

### 2.1 标准结构

```
H1: 文章标题（保持不变）

H2: 什么是 XXX
  → 首句给定义（30 字以内）
  → 后面 1-2 段展开说明

H2: 为什么需要 XXX / 能解决什么问题
  → 首句给结论
  → 用 2-3 个具体场景说明

H2: 如何 [具体动作]
  → 步骤化呈现（有序列表 ol）
  → 每步不超过 3 行文字

H2: 常见问题
  → 3-5 个 FAQ（见第三节写作规范）

H2: 总结
  → 30 字以内核心结论
```

### 2.2 改造示例

**改造前**：
```markdown
## 什么是 HarseTV

HarseTV 是一个 AI 创作平台，集成了多种 AI 模型...

## 使用方法

首先登录网站，然后选择模型，输入提示词，点击生成...

## 注意事项

使用过程中请注意...
```

**改造后**：
```markdown
## 什么是 HarseTV

HarseTV 是一个支持多模型切换的一站式 AI 图像与视频生成平台。它集成了 Seedream、Imagen 3、Kling、Veo 等主流模型，用户无需分别注册各个模型平台，在一个界面内即可完成从文本到图像/视频的创作流程。

## 为什么需要 HarseTV

对于需要频繁切换不同 AI 模型的创作者，HarseTV 可以省去多次登录和配置 API 的麻烦。平台内置统一计费系统，支持按量付费和会员套餐两种模式。

## 如何使用 HarseTV 生成图像

1. 登录 HarseTV 控制台，进入「画布」页面
2. 在节点编辑器的「模型」下拉菜单中选择目标模型（如 Seedream 2.0）
3. 在提示词输入框中填写英文或中文描述
4. 点击「生成」按钮，等待 5-15 秒获取结果

## 常见问题

### HarseTV 支持哪些 AI 图像生成模型？

HarseTV 目前支持 Seedream、Imagen 3、Nano Banana 三种图像生成模型，以及 Kling、Veo 两种视频生成模型。你可以在画布节点的模型下拉菜单中直接切换，无需额外配置 API 密钥。2025 年 Q4 还将接入 Midjourney API 和 Stable Diffusion 3.5。

### 使用 HarseTV 需要付费吗？

HarseTV 采用免费试用 + 按需付费的模式。新用户注册可获赠一定额度的免费调用次数，用完后可选择按量充值或购买会员套餐。图像生成单价从 0.02 美元/张起，视频生成从 0.15 美元/秒起。

## 总结

HarseTV 通过多模型集成和统一计费，帮助创作者在一个平台内高效完成 AI 图像与视频生成。
```

### 2.3 关键规则

| 规则 | 说明 |
|------|------|
| **FAQ 数量 >= 3** | 少于 3 个不部署 FAQPage Schema |
| **FAQ 答案 50-150 字** | 太短 AI 缺乏上下文，太长用户不想读 |
| **首句必须直接回答** | AI 抽取引用时优先抽首句 |
| **避免代词模糊** | 用"HarseTV"不用"它"，用"Seedream 模型"不用"这个模型" |
| **包含 1 个具体事实/数据** | 如价格、数量、时间、版本号 |

## 三、Prompt 页改造规范（3 个固定区块）

Prompt 详情页不需要像文章页那样复杂的结构，在现有描述下方增加 3 个固定区块即可。

### 3.1 标准结构

在 Prompt 详情页的「描述」下方，新增以下区块：

```markdown
## 这个提示词适合什么场景？
→ 首句直接回答场景类型
→ 补充 1-2 个具体使用案例

## 使用步骤
→ 3 步以内，每步 1 行

## 常见问题
→ 2-3 个 FAQ（写法同文章页）
```

### 3.2 改造示例

**以「奢华电影感时尚大片」提示词为例**：

```markdown
## 这个提示词适合什么场景？

这个提示词专为高端时尚摄影和奢侈品广告视觉设计，适合生成杂志封面、品牌 Campaign 主视觉、电商详情页首图。最佳使用场景是需要强烈光影对比、电影级色调和高级质感的人像或静物图像。不适合卡通、扁平插画或日常快照风格。

## 使用步骤

1. 将提示词复制到 HarseTV 画布的文本输入节点
2. 在「模型」下拉菜单中选择 Seedream 2.0 或 Imagen 4
3. 如需调整风格，可修改提示词中的 "cinematic lighting" 为 "soft lighting" 或 "dramatic lighting"

## 常见问题

### 这个提示词用 Seedream 和 Imagen 生成有什么区别？

Seedream 2.0 生成的结果更偏向东方审美，肤色过渡柔和，适合亚洲时尚品牌；Imagen 4 的光影对比更强烈，细节锐度高，适合欧美奢侈品牌的硬朗风格。同一提示词在两模型下的色调倾向会有明显差异，建议根据目标受众选择。

### 为什么生成的结果和示例图不一致？

示例图使用的是特定随机种子（seed=42）和固定参数（CFG=7.5, Steps=30）。由于 AI 模型本身具有随机性，即使使用相同提示词，不同种子也会产生不同构图。如需复现示例效果，请在生成设置中填入相同的种子值和参数。
```

### 3.3 注意

- Prompt 页的 FAQ **只给复杂 Prompt 写**（描述 > 100 字、多参数、多步骤）
- 简单 Prompt（如"油画风格""赛博朋克头像"）不写 FAQ，只写「适用场景」一句话即可
- 内容保存在 Prompt 的 `faq` 字段，前端会自动渲染为 FAQPage Schema

## 四、FAQ 写作 SOP（核心规范）

这是最重要的部分。FAQ 写得好不好，直接决定 GEO 效果。

### 4.1 问题（Question）写法

#### DO（这样做）

| 原则 | 示例 |
|------|------|
| 使用完整自然语言 | ✅ "HarseTV 支持哪些 AI 图像生成模型？" |
| 包含完整主谓宾 | ✅ "使用 HarseTV 需要付费吗，调用 API 怎么计费？" |
| 使用用户真实搜索词 | ✅ "HarseTV 可以在没有网络的情况下使用吗？" |
| 问题长度 15-40 字 | ✅ "如何调整提示词中的光照参数来改变输出风格？" |

#### DON'T（不要这样做）

| 错误类型 | 反面示例 | 问题 |
|---------|---------|------|
| 短语式 | ❌ "支持的模型" | AI 无法理解这是什么问题 |
| 省略主语 | ❌ "费用" | 没有上下文，AI 不知道指什么 |
| 代词模糊 | ❌ "它支持离线吗" | "它"是谁？ |
| 过于笼统 | ❌ "怎么用" | 范围太大，AI 无法精准抽取 |

### 4.2 答案（Answer）写法

#### 黄金公式

```
[首句直接给结论，15-30 字] + [展开说明 1-2 句] + [补充一个具体事实/数据]
```

#### DO（这样做）

| 原则 | 示例 |
|------|------|
| 首句直接回答 | ✅ "HarseTV 目前支持 Seedream、Imagen 3、Nano Banana 三种图像生成模型..." |
| 包含具体数字 | ✅ "...三种图像生成模型，以及 Kling、Veo 两种视频生成模型" |
| 包含操作路径 | ✅ "...你可以在画布节点的模型下拉菜单中直接切换" |
| 包含差异化信息 | ✅ "...无需额外配置 API 密钥（系统已内置统一计费）" |
| 控制字数 50-150 字 | ✅ 太长 AI 抽取困难，太短缺乏上下文 |

#### DON'T（不要这样做）

| 错误类型 | 反面示例 | 问题 |
|---------|---------|------|
| 首句不直接回答 | ❌ "HarseTV 是一个非常强大的平台，它支持很多模型，包括 Seedream、Imagen..." | AI 抽取首句时得不到结论 |
| 纯列表无解释 | ❌ "图像：Seedream、Imagen、Nano Banana 等。视频：Kling、Veo 等。" | 缺乏上下文，AI 无法引用 |
| 代词模糊 | ❌ "它支持离线使用，但功能会受限" | "它"指什么？ |
| 过度营销 | ❌ "HarseTV 是市面上最好的 AI 平台，功能强大，体验一流..." | AI 不引用营销话术 |
| 太长 | ❌ 超过 200 字 | AI 抽取精度下降 |

### 4.3 正反示例对比

**示例 1：关于模型支持**

| | 内容 |

## 六、AI 辅助批量生产流程

为了提效，可以用 AI 生成 FAQ 初稿，但**必须人工审核修改**。

### 6.1 单条 Prompt 生成 FAQ 的 AI Prompt 模板

```
请为以下提示词生成 3 个常见问题及答案。

要求：
1. 问题使用完整自然语言，包含主谓宾，长度 15-40 字
2. 答案首句必须直接回答问题（15-30 字结论）
3. 答案总长度 50-150 字
4. 包含至少 1 个具体数字/事实/操作路径
5. 避免使用"它""这个"等代词，全部用全称
6. 语气客观，不营销不夸张

提示词标题：{title}
提示词描述：{description}
提示词内容：{content}
```

### 6.2 文章生成 FAQ 的 AI Prompt 模板

```
请根据以下文章内容，生成 3-5 个常见问题及答案。

要求：
1. 问题必须是用户真实会问的（how/what/why/which 开头）
2. 答案首句直接给结论
3. 每个答案 50-150 字
4. 包含具体数据、版本号、价格、数量等事实
5. 避免代词模糊，用全称替代"它""这个"
6. 如果文章中缺少具体数据，请标注 [需补充数据]

文章标题：{title}
文章内容：{content}
```

### 6.3 批量生产流程

1. **导出数据**：从后台导出头部 20 篇文章 + 30 个 Prompt 的标题、描述、内容
2. **AI 批量生成**：用上述 Prompt 模板，逐条生成 FAQ 初稿
3. **人工审核**：逐条检查是否符合第四章的写作规范
4. **修改完善**：对不符合规范的进行人工改写
5. **填入后台**：将最终 FAQ 内容填入文章/Prompt 的 `faq` 字段
6. **批量翻译**：使用后台「批量 SEO 翻译」功能，将中文 FAQ 同步翻译为 11 种语言

## 八、常见问题（给运营同学的 FAQ）

**Q1：为什么要改现有内容？不能直接发新文章吗？**

A：改造现有头部内容的 ROI 远高于写新文章。头部内容已经有搜索流量和用户使用数据，改造后效果立竿见影。新文章需要从零积累权重。

**Q2：FAQ 写进 `faq` 字段后，页面上怎么展示？**

A：技术同学已经在前端接好了。只要 `faq` 字段有内容，页面会自动渲染 FAQ 区块，并在页面 `<head>` 中注入 FAQPage Schema。

**Q3：AI 生成的 FAQ 可以直接用吗？**

A：**不可以直接用，必须人工审核**。AI 生成的内容常见问题：首句不直接回答、缺少具体数据、语气偏营销、代词模糊。请严格按照第四章规范修改后再提交。

**Q4：英文/日文等多语言 FAQ 也要人工写吗？**

A：不需要。中文 FAQ 定稿后，使用后台的「批量 SEO 翻译」功能一键翻译成 11 种语言。但翻译后建议抽检几个重点语种（英文、日文）的质量。

**Q5：Prompt 页没有 `faq` 字段怎么办？**

A：后台 Prompt 管理页面已经有 `faq` 字段。如果没有看到，请联系技术同学确认。

---

> **最后提醒**：GEO 优化是一个长期过程，不要指望改完立刻见效。AI 模型的训练数据有滞后性，通常 4-8 周后才能在 AI 回答中看到引用效果。请耐心执行，持续监控数据。
