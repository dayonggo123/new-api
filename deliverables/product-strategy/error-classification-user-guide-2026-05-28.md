## 1. 错误分类总览

### 1.1 分类维度

采用 **"来源 × 性质"** 双维度分类法：

| 错误来源\错误性质 | 认证授权 | 额度计费 | 请求参数 | 上游响应 | 系统内部 |
|------------------|----------|----------|----------|----------|----------|
| **用户侧** | 令牌无效、未授权 | 余额不足 | 参数错误、敏感词 | — | — |
| **渠道侧** | 渠道密钥错误 | 渠道欠费 | 模型映射错误 | 渠道响应异常 | 渠道不可用 |
| **上游侧** | 上游认证失败 | 上游额度不足 | 上游参数拒绝 | 上游返回错误 | 上游服务不可用 |
| **系统侧** | — | — | — | — | 数据库错误、内部异常 |

### 1.2 五大错误类别

| 类别编号 | 类别名称 | 错误数量 | 典型HTTP状态码 |
|----------|----------|----------|----------------|
| A | 认证授权错误 | 6 | 401, 403 |
| B | 额度计费错误 | 4 | 403, 429 |
| C | 请求参数错误 | 6 | 400, 413 |
| D | 上游/渠道错误 | 8 | 502, 503, 504, 429 |
| E | 系统内部错误 | 4 | 500 |

## 2. 详细错误类型与指导动作

### A. 认证授权错误（Authentication & Authorization Errors）

#### A1. 令牌无效/过期（Token Invalid / Expired）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `token.invalid` / `token.expired` |
| **HTTP状态码** | 401 Unauthorized |
| **触发场景** | API Key 错误、Key 已被删除、Key 已过期 |
| **前端当前行为** | 自动跳转登录页 (`window.location.href = '/login?expired=true'`) |
| **是否重试** | 否（skipRetry） |
| **是否退款** | 不涉及 |
| **是否禁用渠道** | 否 |

**用户指导动作**：
- **用户提示**："您的 API Key 无效或已过期，请检查 Key 是否正确，或重新生成 API Key。"
- **操作指引**：前往「令牌管理」页面，确认 Key 状态为「启用」，如已过期请重新创建。
- **管理员提示**：如使用环境变量配置的 Key，请检查 `Authorization` 请求头格式（应为 `Bearer sk-xxx`）。

---

#### A2. 令牌额度耗尽（Token Exhausted）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `token.exhausted` |
| **HTTP状态码** | 403 Forbidden |
| **触发场景** | 令牌剩余额度为 0 或负数 |
| **是否重试** | 否 |
| **是否退款** | 不涉及 |
| **是否禁用渠道** | 否 |

**用户指导动作**：
- **用户提示**："当前 API Key 的额度已耗尽，请联系管理员充值或更换 Key。"
- **操作指引**：管理员可前往「用户管理」→「额度管理」为该用户增加额度。

---

#### A3. 用户被封禁（User Banned）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `user.disabled` / `auth.user_banned` |
| **HTTP状态码** | 403 Forbidden |
| **触发场景** | 用户账号被管理员禁用 |
| **是否重试** | 否 |

**用户指导动作**：
- **用户提示**："您的账号已被禁用，如有疑问请联系管理员。"

---

#### A4. IP 访问受限（IP Access Denied）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `access_denied` |
| **HTTP状态码** | 403 Forbidden |
| **触发场景** | 请求来源 IP 不在令牌允许访问的 IP 白名单中 |
| **是否重试** | 否 |

**用户指导动作**：
- **用户提示**："您的 IP 地址不在该 API Key 的允许访问列表中。"
- **操作指引**：请管理员在「令牌管理」→「IP白名单」中添加您的 IP 地址。

---

#### A5. 渠道密钥无效（Channel Invalid Key）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `channel:invalid_key` / `invalid_api_key` |
| **HTTP状态码** | 401 |
| **触发场景** | 上游返回 API Key 无效 |
| **是否重试** | 否 |
| **是否禁用渠道** | **是**（自动禁用） |

**用户指导动作**：
- **用户提示**："当前服务渠道配置异常，系统已自动切换至备用渠道，请稍后重试。"
- **管理员提示**：「渠道管理」中对应的渠道已被自动禁用，请检查上游 API Key 是否过期或变更。

---

#### A6. 权限不足（Permission Denied）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `permission_error` / `forbidden` |
| **HTTP状态码** | 403 |
| **触发场景** | 用户无权限访问某模型/功能；渠道权限被拒绝 |
| **是否禁用渠道** | **是**（匹配关键词"Permission denied"） |

**用户指导动作**：
- **用户提示**："您没有权限使用该模型或功能，请联系管理员开通权限。"

### B. 额度计费错误（Quota & Billing Errors）

#### B1. 用户额度不足（Insufficient User Quota）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `insufficient_user_quota` |
| **HTTP状态码** | 403 Forbidden |
| **触发场景** | 用户钱包余额 < 预扣费额度；订阅额度不足 |
| **是否重试** | 否 |
| **是否退款** | 不涉及（未扣费） |
| **是否禁用渠道** | 是（`pre_consume_token_quota_failed` 会触发禁用） |

**用户指导动作**：
- **用户提示**："您的账户额度不足，当前剩余额度为 XXX，本次请求需要 XXX。请充值后重试。"
- **操作指引**：点击「充值」按钮前往充值页面，或联系管理员调整额度。

---

#### B2. 订阅额度不足（Subscription Quota Insufficient）

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `insufficient_user_quota`（含"subscription quota insufficient"） |
| **HTTP状态码** | 403 Forbidden |
| **触发场景** | 用户有订阅但订阅剩余额度不足 |
| **是否重试** | 否 |

**用户指导动作**：
- **用户提示**："您的订阅额度已用完，系统已尝试使用钱包余额。如钱包余额不足，请充值后重试。"
- **操作指引**：前往「订阅管理」查看订阅使用情况，或购买更高档位订阅。

---

#### B3. 渠道余额不足（Channel Balance Low）

| **触发场景** | 上游渠道（如 OpenAI、Azure）账户欠费或余额不足 |

- **管理员提示**：渠道因上游余额不足已被自动禁用，请登录上游平台充值后手动启用该渠道。

### D. 上游/渠道错误（Upstream & Channel Errors）

#### D1. 上游服务不可用 — 502 Bad Gateway

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `bad_response_status_code` / `do_request_failed` |
| **HTTP状态码** | 502 Bad Gateway |
| **触发场景** | 上游服务宕机、网络不可达、DNS 解析失败 |
| **是否重试** | **是**（符合重试状态码范围） |
| **是否禁用渠道** | 否（非 401） |

**用户指导动作**：
- **用户提示**："当前系统服务繁忙，正在自动重试，请耐心等待。"
- **替代话术**："上游服务暂时不可用，系统正在尝试切换至备用渠道..."

---

#### D2. 上游服务维护 — 503 Service Unavailable

| 属性 | 内容 |
|------|------|
| **ErrorCode** | `upstream_error` |
| **HTTP状态码** | 503 Service Unavailable |
| **触发场景** | 上游服务维护中、过载保护 |
| **是否重试** | **是**（500-503 在重试范围内） |

**用户指导动作**：
- **用户提示**："系统正在升级维护中，请耐心等待几分钟后重试。"
- **替代话术**："当前分组负载较高，系统正在自动调度，请稍后..."

> 💡 **特别提示**：用户提到"502 时告诉用户现在系统正在升级，请耐心等待"，这属于 503 的标准话术。502 应提示"服务暂时不可用，正在自动切换渠道"。

---

## 3. 异步任务错误（视频/图片生成）

### 3.1 任务专属错误类型

异步任务（视频生成、图片生成）使用独立的 `TaskError` 体系，与同步请求错误有所区别：

| 错误场景 | ErrorCode | 状态码 | 用户指导动作 | 是否退款 |
|----------|-----------|--------|--------------|----------|
| 任务提交失败 | `submit_failed` | 400/500 | "任务提交失败，请检查参数后重试。" | 是 |
| 任务执行失败 | `task_failed` | 400 | "任务执行失败，失败原因：{reason}。已自动退款，请稍后重试。" | **是** |
| 任务超时 | `task_timeout` | — | "任务处理超时，已自动取消并退款，请稍后重试。" | **是** |
| 任务不存在 | `task_not_found` | 404 | "任务不存在或已过期，请重新提交。" | — |
| 获取任务失败 | `get_task_failed` | 500 | "查询任务状态失败，请稍后刷新。" | — |
| 上游查询返回 4xx | — | 400-499 | "任务参数有误或上游任务不存在，已标记为失败并退款。" | **是** |
| 上游查询返回 5xx | — | 500-599 | "上游服务暂时不可用，系统将继续轮询任务状态。" | 否 |

### 3.2 任务失败退款规则

```
任务失败退款触发条件：
├─ 任务状态变为 FAILURE（任何原因）
├─ 任务超时（超过 TaskTimeoutMinutes）
├─ 且任务 quota > 0
├─ 且不是旧系统遗留任务（2026-02-22 前）
└─ 退款路径：wallet/subscription → token quota
```

### 3.3 用户指定场景：非系统原有视频创建失败

> 用户特别要求："出现非系统原有视频创建失败或者生成失败时，则提示用户请重新生成，失败不扣费"

**判定条件**：
- 任务状态为 `FAILURE`
- `FailReason` 不为空
- 错误来源为上游（非系统内部错误）

**用户指导动作**：
- **用户提示**："视频生成失败，失败原因：{fail_reason}。本次请求未扣费，请修改参数后重新生成。"
- **扣费说明**：系统已自动退还预扣额度，您可放心重试。
- **建议操作**：检查提示词是否过长、是否包含不支持的内容描述、是否选择了正确的视频尺寸。

## 5. HTTP 状态码与用户话术速查表

| HTTP 码 | 技术含义 | 用户话术 | 操作指引 |
|---------|----------|----------|----------|
| 400 | 请求参数错误 | "请求参数错误，请检查输入。" | 检查必填字段和 JSON 格式 |

| 503 | 服务维护 | "系统升级维护中，请耐心等待。" | 几分钟后重试 |
| 504 | 上游超时 | "请求超时，可能仍在处理中。" | 稍后查询结果 |
